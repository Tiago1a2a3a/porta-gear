PORTA GEAR — Manual de Operação e Comandos

Controle de Acesso Local • Luckfox Pico Ultra (Linux Buildroot / RV1106) • Leitor PN532 SPI • Relé KY-019
Status Atual do Sistema: Banco de dados 100% limpo (virgem) e inicializado. O sistema opera de forma totalmente síncrona, robusta e bloqueante (sem concorrência frágil ou threads).

1. Entendendo os Modos de Operação

O leitor RFID/NFC Funduino PN532 V3 é acessado via barramento SPI físico (/dev/spidev0.0). Como o barramento SPI não permite que dois processos conversem com o leitor ao mesmo tempo, o sistema possui dois modos de trabalho:

Modo Produção (Padrão)

O processo da porta (executar) mantém o leitor aberto e monitorando continuamente aproximações de cartões para liberar a fechadura.

  • Leitor: Ocupado monitorando a porta
  • Porta: Abre automaticamente para tags cadastradas
  • Comandos liberados: Consultas, listagens, ativações/remoções e histórico
  • Comandos protegidos: novo-usuario e trocar-cartao ficam bloqueados para não haver conflito de hardware

Modo Cadastro

Modo administrativo para incluir novas pessoas ou trocar cartões no leitor sem precisar desligar a placa ou matar o sistema.

  • Leitor: Liberado pelo serviço principal
  • Porta: Pausada temporariamente
  • Comandos liberados: TODOS, incluindo novo-usuario e trocar-cartao
  • Retorno simples: Basta rodar modo-producao ao terminar

2. Como Alternar entre os Modos na Prática

Fluxo Recomendado com 2 Terminais (ou Janelas SSH / ADB)

1
Terminal 1 (Porta Rodando): Deixe o serviço da porta rodando em primeiro plano: 
python3 main.py executar
2
Terminal 2 (Administrador): Quando precisar cadastrar alguém, mude para cadastro: 
python3 main.py modo-cadastro
O Terminal 1 informará que o leitor foi liberado instantaneamente.
3
Terminal 2: Cadastre o novo usuário ou troque a tag: 
python3 main.py novo-usuario
4
Terminal 2: Volte o sistema para a produção normal: 
python3 main.py modo-producao
O Terminal 1 reabre o leitor e retoma o controle de acesso da porta.
Dica para uso com 1 terminal apenas: Você pode iniciar o serviço em segundo plano adicionando & ao final:
python3 main.py executar &
Dessa forma, o seu terminal não fica preso e você pode digitar modo-cadastro e modo-producao diretamente na mesma janela.

3. Tabela Completa de Comandos

Comando Modo Requerido Descrição e Exemplo de Uso
python3 main.py status Qualquer Exibe modo atual, se o serviço da porta está ativo (com PID), estado do leitor (livre/ocupado) e quantidade de usuários.
python3 main.py modo-cadastro Qualquer Solicita que o serviço da porta libere o PN532 para permitir novos cadastros.
python3 main.py modo-producao Qualquer Reativa o leitor PN532 no serviço principal e retoma a liberação automática da porta.
python3 main.py executar Produção Inicia o loop contínuo que lê as tags, valida no SQLite e aciona o relé (GPIO 52).
python3 main.py novo-usuario Cadastro Assistente interativo. Pede o nome, gera o próximo ID (ex: 001) e lê a tag no leitor.
python3 main.py novo-usuario --nome "Tiago Silva"
python3 main.py trocar-cartao
(alias: novo-cartao)		 Cadastro Substitui o cartão de um usuário existente.
python3 main.py trocar-cartao --id 001
python3 main.py trocar-cartao --nome "Tiago"
python3 main.py listar-usuarios Qualquer Lista todos os usuários com ID, Nome, UID do cartão e estado (ativo/inativo).
python3 main.py ativar-usuario Qualquer Reativa o acesso de um usuário suspenso: --id 001
python3 main.py desativar-usuario Qualquer Bloqueia o acesso sem apagar a pessoa do histórico: --id 001
python3 main.py remover-usuario Qualquer Desativa, renomeia com sufixo -exl e libera o cartão para uso futuro: --id 001
python3 main.py alterar-usuario Qualquer Altera nome ou estado de um usuário: --id 001 --nome "Novo Nome"
python3 main.py cadastrar-usuario Qualquer Cadastro manual direto por parâmetros (sem usar o leitor):
--id 001 --nome "Ana" --uid AABBCCDD
python3 main.py registros Qualquer Exibe os acessos recentes com data, hora, ID, nome e se foi autorizado ou negado.
python3 main.py registros --limite 20
python3 main.py abrir-porta Qualquer Aciona o relé da fechadura manualmente via terminal.
python3 main.py ler-cartao Cadastro Lê uma tag avulsa no PN532 para teste ou identificação de UID.
python3 main.py inicializar-banco Qualquer Cria a estrutura de tabelas SQLite caso o arquivo de banco seja recriado.

4. Resumo de Hardware e Configuração Física

  • Placa controladora: Luckfox Pico Ultra (Rockchip RV1106G3, Linux Buildroot).
  • Leitor RFID: Funduino PN532 V3 em modo SPI (DIP Switch 1=ON, 2=OFF). Conectado em /dev/spidev0.0 a 500 kHz.
  • Relé da Fechadura: Módulo Relé KY-019 acionado pelo pino GPIO 52 (ativo alto: nível 1 liga relé e destrava a fechadura por 1 segundo).
  • Banco de Dados Local: SQLite armazenado em /root/Projeto_tiago/data/access_control.sqlite3 com integridade referencial e auditoria completa.
